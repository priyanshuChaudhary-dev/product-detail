# 🛍️ Product Details App

A modern React application that fetches and displays random product details from an API with a beautiful, responsive UI.

## 📋 Features

- **Random Product Display**: Fetches random products from the API
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Beautiful UI**: Modern gradient design with smooth animations
- **Next Product Button**: Easy navigation to view different products
- **Loading States**: User-friendly loading indicators
- **Error Handling**: Graceful error management
